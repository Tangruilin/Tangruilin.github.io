Mac环境下配置iceberg-cpp开发环境

发表于 2025-09-21
本文字数： 442 阅读时长 ≈ 2 分钟

背景

最近, iceberg-cpp 项目 0.1 版本 release 发布, 具体信息参考 iceberg-cpp 1.0 Release 发布。当前版本在国内使用 Mac 编译时, 存在一些问题, 本文记录并解决这部分编译问题。

问题说明

目前编译下来主要有两个问题:

  1. 部分依赖使用 github 上 tar 包, 直接编译的情况下会有下载报错, 以下表格中整理所有需要提前下载好的 tar 包(拷贝目标路径默认 cmake 预构建到 build 目录下)

    依赖 软件包 拷贝目标路径 下载地址
    croaring v4.3.11.tar.gz build/_deps/croaring-subbuild/croaring-populate-prefix/src/v4.3.11.tar.gz https://gh.llkk.cc/https://github.com/RoaringBitmap/CRoaring/archive/refs/tags/v4.3.11.tar.gz
    nanoarrow apache-arrow-nanoarrow-0.7.0.tar.gz build/_deps/nanoarrow-subbuild/nanoarrow-populate-prefix/src/apache-arrow-nanoarrow-0.7.0.tar.gz https://dlcdn.apache.org/arrow/apache-arrow-nanoarrow-0.7.0/apache-arrow-nanoarrow-0.7.0.tar.gz
    apache-arrow apache-arrow-21.0.0.tar.gz build/_deps/vendoredarrow-subbuild/vendoredarrow-populate-prefix/src/apache-arrow-21.0.0.tar.gz https://gh.llkk.cc/https://github.com/apache/arrow/releases/download/apache-arrow-21.0.0/apache-arrow-21.0.0.tar.gz
    boost boost-1.88.0-cmake.tar.gz build/_deps/boost-subbuild/boost-populate-prefix/src/boost-1.88.0-cmake.tar.gz https://gh.llkk.cc/https://github.com/boostorg/boost/releases/download/boost-1.88.0/boost-1.88.0-cmake.tar.gz
    thrift thrift-0.22.0.tar.gz build/_deps/thrift-subbuild/thrift-populate-prefix/src/thrift-0.22.0.tar.gz https://www.apache.org/dyn/closer.lua/thrift/0.22.0/thrift-0.22.0.tar.gz?action=download;https://dlcdn.apache.org/thrift/0.22.0/thrift-0.22.0.tar.gz

  2. 部分依赖使用 https 协议从 github.com 拉取源码, 此部分修改为 ssh 协议可解

    例如:

    将 GIT_REPOSITORY 修改为 git@github.com:google/googletest.git 即可

  3. MacOS 平台下没有 cpu_set_t, 但是 google-benchmark 在探测到支持 cpu 绑核时, 直接使用了 linux 下的 api, 因此在 Mac 平台下会编译失败。具体可参考, Mac 下编译 iceberg-cpp 失败

    目前 google-benchmark 应该是只在编译 MICROBENCHMARKS 时会用到绑核, 默认关闭即可, flag 为 DENABLE_ROARING_MICROBENCHMARKS=OFF
